# TruthTellerBot 🕵️

**TruthTellerBot** — это Telegram-бот для отслеживания изменений и удалений сообщений в ваших личных чатах через Telegram Business API. Бот работает по принципу "нулевого хранения" — не сохраняет сообщения надолго, а уведомления отправляет только в ваш личный чат с ботом.

## 🚀 Возможности

- ✅ **Отслеживание изменений сообщений** — получайте уведомления о редактированных сообщениях с показом старого и нового текста.
- ✅ **Отслеживание удаленных сообщений** — узнавайте, какие сообщения были удалены из ваших чатов.
- ✅ **Отслеживание стикеров** — удаленные стикеры также сохраняются и отслеживаются.
- ✅ **Сохранение медиафайлов** — удаленные фото, видео, документы, голосовые, видеосообщения и стикеры временно сохраняются в вашем S3-совместимом хранилище.
- ✅ **Умное получение медиа** — команда `/get_latest_media` всегда отдает именно тот файл, о котором шла речь в последнем уведомлении.
- ✅ **Стандартизированные уведомления** — единый формат уведомлений с форматированием MarkdownV2 и автоматическим fallback на plain text.
- ✅ **Многоязычность** — поддержка русского и английского языков с возможностью переключения.
- ✅ **Краткосрочное хранение** — сообщения кэшируются в Redis на 2 минуты. Медиафайлы в S3 также удаляются автоматически.
- ✅ **Безопасность** — принцип stateless, никакие данные не сохраняются надолго.
- ✅ **Форматированные уведомления** — красивые уведомления с поддержкой MarkdownV2 и автоматической обработкой ошибок.
- ✅ **Централизованное логирование** — подробные логи с временными метками для отладки.
- ✅ **Система статистики** — автоматический сбор продуктовых метрик (MAU/DAU, Activation Rate, Retention, Trial CR) в MongoDB.
- ✅ **Мониторинг** — встроенный Grafana + Prometheus для мониторинга Redis и MongoDB.

## 🛠️ Технический стек

- **Runtime:** Bun
- **Язык:** TypeScript
- **Framework:** Telegraf.js
- **API:** Telegram Business API
- **Кэширование:** Redis
- **БД:** MongoDB (**Mongoose**) с коллекцией статистики
- **Хранение файлов:** S3-совместимое хранилище (Yandex Object Storage, Selectel, MinIO и др.)
- **Мониторинг:** Grafana + Prometheus с экспортерами для Redis и MongoDB
- **Интеграция платежей:** Tribute (webhooks с проверкой подписи HMAC-SHA256)

## 📋 Требования

1. **Telegram Premium** подписка (для доступа к Telegram Business).
2. **Redis** сервер.
3. **MongoDB** (запускается через docker-compose).
4. **S3-совместимое хранилище** и его учетные данные.
5. **Bun** v1.0.0 или выше.
6. **Node.js** (для совместимости с некоторыми пакетами).

## ⚙️ Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <your-repository-url>
cd truthteller-bot
```

### 2. Установка зависимостей

```bash
bun install
```

### 3. Настройка переменных окружения

Создайте файл `.env` в корне проекта, скопировав `.env.example`:

```bash
cp env.example .env
```

Отредактируйте файл `.env`, указав **все** необходимые параметры (фрагмент):

```env
WEBHOOK_URL=
TELEGRAM_WEBHOOK_PATH=/telegraf/truthteller
TRIBUTE_PREMIUM_URL=https://t.me/tribute/app?startapp=sxl5
TRIBUTE_API_KEY=

REDIS_URL=redis://localhost:6379
MONGODB_URI=mongodb://spybot:spybot@mongo:27017/spybot?authSource=admin

S3_BUCKET=
S3_REGION=
S3_ENDPOINT=
S3_KEY=
S3_SECRET=
```

### 4. Запуск с Docker Compose (Рекомендуемый способ)

```bash
docker-compose up -d --build
```

**Управление контейнерами:**

- `docker-compose logs -f app | cat` — просмотр логов бота.
- `docker-compose down -v` — остановка и удаление контейнеров и данных.

**Структура Docker:**

- `redis` — Redis сервер для кэширования.
- `redis-exporter` — экспортер метрик Redis для Prometheus.
- `mongo` — MongoDB база данных (персистентные данные).
- `mongodb-exporter` — экспортер метрик MongoDB для Prometheus.
- `prometheus` — сервер метрик Prometheus.
- `grafana` — веб-интерфейс для визуализации метрик.
- `app` — приложение TruthTellerBot.

### 5. Проверка доступности и вебхука

- Health‑чек:
  - `curl -i "$WEBHOOK_URL/"` → 200 OK
  - `curl -i "$WEBHOOK_URL/_health"` → 200 OK
- В логах должна быть строка `WebhookInfo` с корректным `url`.
- Команда `/start` доступна всем пользователям.

### 6. Настройка мониторинга

После запуска `docker-compose up -d` доступны интерфейсы:

- **Prometheus:** http://<ваш_сервер>:9090
- **Grafana:** http://<ваш_сервер>:3001
  - Логин по умолчанию: `admin` / `admin`
  - Prometheus автоматически добавлен как источник данных при первом запуске

Настройте переменные в `.env`:

```env
GRAFANA_IP=<ваш_IP_адрес>
GRAFANA_ADMIN_USER=admin
GRAFANA_ADMIN_PASSWORD=<ваш_пароль>
```

### 7. Подключение к MongoDB через MongoDB Compass

🔒 **Подробная инструкция по безопасному подключению:** [MONGO_COMPASS_SETUP.md](./MONGO_COMPASS_SETUP.md)

Краткая инструкция:

1. Установите креды в `.env`:

```env
MONGO_INITDB_ROOT_USERNAME=spybot
MONGO_INITDB_ROOT_PASSWORD=your_secure_password
MONGO_PORT=27017
```

2. Подключитесь через Mongo Compass:

```
mongodb://spybot:your_secure_password@localhost:27017/?authSource=admin
```

⚠️ **ВАЖНО**: Измените пароль по умолчанию на безопасный!

## 📱 Команды бота

- `/start` — запуск и краткая инструкция (только владелец).
- `/get_latest_media` — получить последний сохраненный медиафайл.
- `/help` — справка по использованию.
- `/set_language` — сменить язык интерфейса.
- `/premium` — информация о Premium и ссылка на оплату.
- `/referral` — получить реферальную ссылку.
- `/feedback` — оставить отзыв или предложение.

## 💎 Монетизация и подписки

- **Интеграция с Tribute** — обработка webhook для автоматической активации подписок.
- **Статусы подписки:** FREE и PREMIUM, хранятся в MongoDB.
- **Бесплатный триал** — 14 дней для новых пользователей.
- **Ограничения FREE:** отслеживание только одного чата после окончания триала.
- **Реферальная программа** — бонусы за приглашение друзей.

## 📊 Статистика и аналитика

Система автоматически собирает продуктовые метрики в MongoDB (коллекция `stats`):

- **MAU/DAU** — активные пользователи за месяц/день (инкрементальное обновление).
- **Activation Rate** — конверсии в целевые действия:
  - Первый старт (`first_start`)
  - Клик по кнопке Premium (`premium_button_click`)
  - Оплата Premium (`premium_payment`)
  - Клик по кнопке реферала (`referral_button_click`)
  - Успешный реферал (`referral_success`)
  - Первое получение уведомления (`first_notification_received`)
- **Retention** — удержание за месяц (формула: ((Клиентов на конец периода - Новых клиентов за период) / Клиентов на начало периода) × 100%).
- **Trial CR** — конверсия из триала в Premium (пользователи, оплатившие после триала / пользователи, завершившие триал × 100%).

**Оптимизация:** используется батчинг запросов (до 50 событий) и инкрементальные обновления для минимизации нагрузки на MongoDB.

## 🔒 Безопасность и приватность

- **Нулевое долгосрочное хранение:** Сообщения хранятся в Redis не более 2 минут.
- **Ваш личный S3:** Медиафайлы выгружаются в ваш S3 и автоматически удаляются через 2 минуты (или сразу после запроса).
- **Доступ только владельцу:** Только владелец бота (по `OWNER_ID`) имеет доступ к командам.

## 🚧 Ограничения

1. Требуется Telegram Premium для доступа к Business API.
2. Требуется Redis, MongoDB и S3-хранилище.
3. Кэш ограничен по времени — сообщения старше 2 минут не отслеживаются.

## 🐛 Устранение неполадок

- **Бот не отвечает:** Проверьте `BOT_TOKEN`, `OWNER_ID`, `WEBHOOK_URL`, `TELEGRAM_WEBHOOK_PATH`.
- **Health 404 через туннель:** проверьте `curl -i "$WEBHOOK_URL/"` и `/_health`, убедитесь, что туннель указывает на порт приложения (`PORT`).
- **Не приходят веб‑хуки Tribute:** путь `.../tribute-webhook`, заголовок `trbt-signature`, ключ `TRIBUTE_API_KEY`.
- **MarkdownV2 ошибки:** используйте безопасные символы или экранирование.
